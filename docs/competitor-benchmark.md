## 2. What the strongest sites do well

### Pattern A — prove scale without relying only on adjectives
Jabal Omar uses development phases and project metrics as credibility signals. Taiba and AlUla also surface portfolio quantities and asset-type breakdowns. Dyafa should use the same principle, but only with approved numbers.

### Pattern B — create a real investment pathway
ASFAR exposes investment journeys and destination/site investment concepts. Rua Al Madinah uses project-level investment opportunity content. This is a major pattern for Dyafa: an investor/owner should be able to understand the opportunity, qualification logic, partnership model, and next step without hunting through the website.

### Pattern C — show the ecosystem, not a list of services
Red Sea Global makes its integrated capabilities and subsidiaries a visible part of the story. Dyafa should make its own ecosystem visible while staying focused on the development arm.

### Pattern D — explain the place and the product
Diriyah, Soudah and KEC connect location, place, demand, destination logic, and development. Dyafa should use location storytelling, but with an investment/development lens rather than a destination-luxury lens.

### Pattern E — build education as a commercial asset
JLL/CBRE/Colliers are useful content benchmarks because research, data, reports and downloadable assets create credibility and capture demand. Dyafa can own practical hospitality-development education for landowners and investors.

### Pattern F — make the owner journey explicit
Marriott's current development experience makes the process and owner contact explicit. Dyafa should use an even more qualification-oriented journey: submit site → initial review → qualification → development discussion.

## 3. Current live observations to encode into the build

- Red Sea Global currently presents integrated capabilities, portfolio, investment, destinations, services, subsidiaries, news, and a newsletter/contact capture path.
- ASFAR currently presents strategic investments, destination investments, site investments, investor CTAs, and private/public partnership positioning.
- Taiba currently presents a portfolio, active properties/keys, projects, partnership CTA, FAQs, and hospitality/real-estate positioning.
- Dur currently presents a diversified hospitality portfolio, investor relations, leadership, hotels, residential communities, serviced apartments, and a searchable portfolio.
- Rua currently presents development/investment positioning and specific investment-opportunity information.
- AlUla Development Company currently positions itself as a gateway to investment opportunities across hospitality, residential, retail, commercial and infrastructure.
- KEC currently shows city-level land area, target residents, hotel keys, project areas, sectors, investment and transport/location context.
- Diriyah currently combines master planning, residences, offices, retail, hotels, investment, partnerships and large project metrics.
- Soudah currently combines project area, zones, culture/heritage, sustainability, community and destination development.
- Emaar currently uses property/community discovery, filters/search, virtual exploration, blogs and lead capture.
- Marriott's development site currently makes managed vs franchised pathways, brand fit, and a development contact form explicit.

## 4. What NOT to copy

- Mega-project visual excess that makes Dyafa look larger than it is.
- Luxury-only positioning.
- Generic "building the future" statements.
- Decorative 3D renders without development logic.
- Huge statistic walls with unverified numbers.
- Investor language that implies guaranteed returns.
- Destination storytelling that hides the actual development proposition.
- Complex navigation that forces every audience through the same path.

## 5. Dyafa's own website advantage

### The unique concept: "Operating Asset Engine"

The visual and content system should repeatedly show a transformation:

**Opportunity → Site → Demand → Product → Feasibility → Structure → Development → Readiness → Operations → Value**

This becomes the signature pattern across the site. It is not a copied mega-project aesthetic; it is an operating/development intelligence interface.

## 8. Final benchmark decision

Do not make the website a collage of competitor ideas. Build a single operating system whose strongest lessons are:

- RSG → ecosystem and lifecycle proof
- ASFAR → opportunity-led investment journey
- Rua → project-level opportunity detail
- Taiba/Dur → portfolio + operation credibility
- Jabal Omar → approved numbers and phase proof
- Diriyah/Soudah/KEC → place + demand + development storytelling
- Emaar → discovery and UX
- JLL/CBRE → insight and data
- citizenM → product standardisation
- Marriott → owner/developer conversion flow

**Dyafa must feel more focused, more disciplined, more operational and more useful than any one competitor site.**
